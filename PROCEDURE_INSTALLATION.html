🛠 Installation backend inerWeb CCF EP2

5 étapes, ~5 minutes. Tout le code est déjà écrit, tu fais juste les clics côté Google.

✓ Ce qui est déjà fait : tout le code (HTML / JS / Apps Script). Tu n'as RIEN à coder.
⚠ Pré-requis : être connecté avec ton compte inerweb.fh@gmail.com dans le navigateur.

1Créer le Google Sheet (30 sec)

  1. Va sur https://sheets.new (raccourci pour créer un Sheet vide).
  2. Renomme-le : inerWeb_CCF_EP2_2026 (clic sur "Feuille de calcul sans titre" en haut à gauche).
  3. Ne touche à rien d'autre. Les feuilles seront créées automatiquement par le script.

2Ouvrir l'éditeur Apps Script (10 sec)

  1. Dans le Sheet : menu Extensions > Apps Script.
  2. Un nouvel onglet s'ouvre avec un projet vide nommé "Sans titre".
  3. Renomme le projet (en haut à gauche) : inerWeb_CCF_EP2_Backend.

3Coller le code (30 sec)

  1. Dans l'éditeur Apps Script, efface tout le code par défaut (Ctrl+A puis Suppr).
  2. Ouvre le fichier apps-script/Code.gs de ce projet (sur ton PC).
  3. Copie tout son contenu (Ctrl+A, Ctrl+C) et colle-le dans l'éditeur Apps Script (Ctrl+V).
  4. Modifie la clé API (ligne 22) : remplace EP2-2026-fh-changeMe par une chaîne que tu choisis (ex : EP2-2026-fh-mavraikeySecrete). Note-la, tu en auras besoin à l'étape 5.
  5. Enregistre (icône disquette ou Ctrl+S).
💡 Tu peux aussi copier le contenu de apps-script/appsscript.json dans le fichier du même nom (clic sur ⚙ en haut à gauche dans Apps Script > "Afficher le fichier de configuration appsscript.json"). C'est facultatif mais ça donne le bon fuseau horaire.

4Déployer comme application web (1 min)

  1. Bouton Déployer (en haut à droite) > Nouveau déploiement.
  2. Clique sur l'engrenage ⚙ à gauche > sélectionne Application Web.
  3. Renseigne :
    • Description : v1 EP2 2026
    • Exécuter en tant que : Moi (inerweb.fh@gmail.com)
    • Qui a accès : Tout le monde (oui, vraiment — c'est la clé API qui protège)
  4. Clique Déployer.
  5. Une fenêtre d'autorisation s'ouvre :
    • Clique Autoriser l'accès
    • Choisis ton compte inerweb.fh@gmail.com
    • Ignore l'avertissement "non vérifié" → Avancé > Accéder à inerWeb_CCF_EP2_Backend (non sécurisé)
    • Accepte tous les scopes (Sheets + Drive)
  6. Une fois déployé, COPIE l'URL d'application web qui s'affiche (commence par https://script.google.com/macros/s/... et finit par /exec).
🎯 Cette URL est ce qu'il faut brancher dans l'app à l'étape 5.

5Brancher l'app sur le backend (30 sec)

  1. Ouvre l'app inerWeb EP2.
  2. Au premier lancement, le modal Configuration backend s'ouvre tout seul.
  3. Remplis :
    • URL Apps Script : colle l'URL copiée à l'étape 4 (finit par /exec)
    • Clé API : la chaîne que tu as choisie à l'étape 3 (ex : EP2-2026-fh-mavraikeySecrete)
    • Tes initiales : FH
  4. Clique 🔍 Tester la connexion.
  5. Si tu vois ✓ Connexion OK avec la liste des feuilles → 💾 Enregistrer.
  6. Le bouton "⚠ Config" en haut à droite devient "✓ Config" vert.

🎉 C'est fini

Maintenant à chaque saisie :

  • 📊 Note → poussée automatiquement dans la feuille Notes du Sheet (append-only avec versionnage)
  • 📷 Photo → uploadée dans Drive/inerWeb_Photos_CCF_EP2_2026/<pseudo>/ + lien dans la feuille Photos
  • ✍ Signature → idem dans Drive/.../<pseudo>/ + feuille Signatures
  • 📜 Audit → toutes les actions loguées dans la feuille _AUDIT_LOG

🆘 En cas de souci

SymptômeSolution
"⚠ Config" reste orange après saveRecharger la page (F5)
Test connexion échoue avec "CLE_API_INVALIDE"La clé saisie ne correspond pas à CLE_API dans Code.gs. Re-vérifie ligne 22.
Test connexion échoue avec HTTP_404L'URL est mauvaise. Doit finir par /exec (et non /dev).
"Erreur 401/403" lors d'un uploadRedéploie l'Apps Script (Déployer > Gérer les déploiements > engrenage > nouvelle version).
Le badge "📎 X en attente sync" reste élevéBackend en panne ou URL invalide. Les pièces sont en sécurité dans IndexedDB (localement). Re-tester la config.
Tu veux voir l'auditOuvre le Sheet, onglet _AUDIT_LOG
Tu veux changer la clé APIModifie ligne 22 du Code.gs, redéploie (Nouveau déploiement, garder la même URL), puis modifie la config dans l'app

🔐 Sécurité & RGPD

  • Les vrais noms d'élèves ne sont JAMAIS envoyés au Sheet/Drive — uniquement les pseudos (ABadis, etc.)
  • La table de correspondance pseudo↔vrai nom reste sur ton PC uniquement (USB côté prof maître)
  • Photos : conserve la consigne "pas de visages dans le cadre" lors de la prise. Si un visage passe, supprime la photo et reprend.
  • Le Drive est partagé "lien visible par l'établissement" → Lakhera y a accès, pas les élèves
  • Suppression automatique fin d'année : à faire manuellement le 31/08 (supprimer le dossier Drive + archiver une copie du Sheet)
