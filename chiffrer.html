🔐 Chiffrer la table des élèves

Outil pour générer ou re-générer le fichier data/eleves_chiffre.json avec ton propre mot de passe.

⚠ RGPD : Cette page tourne 100% en local dans ton navigateur. Aucune donnée n'est envoyée nulle part. Le mot de passe et les noms restent sur ton PC.

1. Choisir le mot de passe

💡 Conseil : choisis quelque chose de mémorable mais pas évident (pas "1234" ni "azerty"). 8+ caractères c'est bien.

2. Table de correspondance E0X → pseudo lisible

3. Chiffrer et télécharger

4. Installer le fichier

  1. Le fichier eleves_chiffre.json est téléchargé dans ton dossier Téléchargements.
  2. Copie-le dans le dossier data/ de ton projet local C:\Users\henni\inerweb-cap-ifca-eval-ep2\data\ (écrase l'ancien).
  3. Commit + push GitHub : 
    cd C:\Users\henni\inerweb-cap-ifca-eval-ep2
git add data/eleves_chiffre.json
git commit -m "MAJ table chiffrée des élèves"
git push
  4. Attends 1-2 min pour que GitHub Pages se redéploie.
  5. Recharge l'app → bouton 🔓 Déverrouiller noms → saisis ton mot de passe.
